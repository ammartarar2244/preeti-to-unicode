Legacy fonts like Preeti are visual layout fonts (typed according to appearance, where the short 'i' matra is typed before the consonant). Unicode is a logical layout font (where the 'i' matra is written after). The converter must reorder these characters during conversion to maintain correct spelling.

Preeti is an ASCII font. The text itself *is* technically English characters. To view it as Devanagari, select the text block in your design application (InDesign, MS Word) and set its font-family to "Preeti".
