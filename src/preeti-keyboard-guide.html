💡 Pro Typing Tip for Beginners

In the Preeti layout, the short 'i' vowel mark (ि) is keyed before the letter it attaches to (type l then s for कि). If you write in modern Unicode Devanagari, you type the consonant first and the matra second. To write without memorizing legacy key positions, try our free phonetic English to Nepali Typing Tool.
