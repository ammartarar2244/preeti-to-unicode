The Complete Guide to Romanized Nepali Keyboard Typing

Writing in the Devanagari script on computers used to be a major headache because traditional Nepali typewriters had highly complex layouts. To make things much simpler, the FOSS Nepal community and Madan Puraskar Pustakalaya came up with the **Nepali Romanized layout** (which most people just call Romanized Unicode). This system maps Nepali characters phonetically to standard QWERTY English keys. It means anyone who knows the English alphabet can start typing in Nepali right away!

How the Romanized Keyboard Layout Works

The layout is designed to map keys based on how they sound. To write aspirates (the "heavier" breathing sounds in Nepali grammar), you just hold the **Shift** key while pressing the base key. Here is a handy chart showing how the keys map:

English Key Mapped Devanagari Shift + Key Shift Devanagari
k क (Ka) K ख (Kha)
g ग (Ga) G घ (Gha)
t त (Ta) T थ (Tha)
d द (Da) D ध (Dha)
p प (Pa) P फ (Pha)

Typing Half-Letters and Joint Words (Conjuncts)

In Nepali, writing half-letters (like the स् in नमस्ते) is done using a special symbol called the **Halant** (्). In our Romanized keyboard layout, the halant is mapped to the forward slash / key.

Here is a quick example of how you would type नमस्ते:

  1. Type n to write न.
  2. Type m to write म.
  3. Type s to write स.
  4. Type / (the halant key) to chop it in half to स्.
  5. Type t to write त.
  6. Type e to add the vowel sign े.

And just like that, नमस्ते will render on your screen in real time!
