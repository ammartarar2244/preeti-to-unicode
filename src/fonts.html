Universal Installation Guidelines

All fonts provided in our center are standard TrueType Font (.ttf) files. They are compatible with all modern systems including Windows, macOS, Linux, and major graphics applications (Adobe Photoshop, Illustrator, InDesign, CorelDRAW, and MS Word).

System-Wide Setup:

Windows OS

  1. Download the font file (.ttf).
  2. Open your Downloads folder, right-click the font, and select Install for all users.
  3. Launch your word processor; select the font to begin writing.

macOS

  1. Download the font (.ttf).
  2. Double-click the file in Finder to open the macOS Font Book.
  3. Click the Install button in the dialogue.
